This folder preserves the earlier combined academic report and its source: [labs-01-02.pdf](labs-01-02.pdf), [labs-01-02.tex](labs-01-02.tex), and [labs-01-02-summary.png](labs-01-02-summary.png). It is supplementary material, not the exact hand-in location for either assignment.

The current separate lab folders contain the original handouts and required files: [Lab 1](../lab1/README.md) and [Lab 2](../lab2/README.md). The report source and its local figure references remain together here.

## Build the supplementary report PDF

With Tectonic installed, run `tectonic labs-01-02.tex` from this folder. This writes `labs-01-02.pdf` here. The report class and UTM logo are included beside the source, so the build does not depend on a separate `report-template` folder.
